# git-churn-chart

ローカルのGitリポジトリについて、日ごとのコード行数の変化をグラフにする。

- 追加した行（棒、0より上）
- 削除した行（棒、0より下）
- 純増の累計（線）。純増は「追加 − 削除」である。

横軸は日付、縦軸は行数である。

期間は、今日までの1週間（7日）・2週間（14日）・1か月（30日）である。ページの上のボタンで切り替える。最初は2週間が出る。純増の累計は、選んだ期間の最初の日から数える。

グラフは3つ出る。上から順に、次のとおりである。

1. コード本体（テストを除く）
2. テストコード
3. すべてのファイル

### コードの範囲

「コード本体」と「テストコード」は、次の拡張子のファイルだけを数える。対象の拡張子は、グラフの見出しにも出る。

| 言語                   | 拡張子                                  |
| ---------------------- | --------------------------------------- |
| Rust                   | `.rs`                                   |
| Swift                  | `.swift`                                |
| Kotlin                 | `.kt`                                   |
| C#・XAML               | `.cs` `.xaml`                           |
| Emacs Lisp             | `.el`                                   |
| TypeScript・JavaScript | `.ts` `.tsx` `.js` `.jsx` `.mjs` `.cjs` |

- ドキュメント、設定（JSON、TOML、YAMLなど）、ロックファイル、画像は数えない。
- HTML・CSSも数えない。
- スクリプトも数えない。シェル、PowerShell、バッチ、Python、Kotlin Script（`.kts`）である。
- 名前を変えたファイルは、新しいパスで判定する。
- 一覧は`src/code.ts`の`CODE_EXTENSIONS`にある。

### テストコードの範囲

コードのうち、次のどれかに当たるものをテストコードとする。残りがコード本体である。

- テスト用のディレクトリの中にある。
  - 名前が`test`、`tests`、`__tests__`、`e2e`、`androidTest`、`spec`、`specs`のどれかである。
  - または、名前が`Tests`、`.Tests`、`-tests`などで終わる。たとえば`AppCoreTests`、`App.Tests`、`viewer-tests`である。
- ファイル名が、テストを表す語で始まるか終わる。たとえば`tests.rs`、`sync_tests.rs`、`parser.test.ts`、`parser.spec.ts`、`ParserTests.swift`、`ParserTest.kt`である。
- Rustのファイルの中で、`#[cfg(test)]`の付いた定義の中にある。ふつうは`mod tests { ... }`である。

Rustは、本体と同じファイルにテストを書ける。そこで、Rustだけは行単位で分ける。

- この切り分けは推定である。ファイル全体は読まず、変更した行と、Gitが出す変更箇所の見出しだけを使う。
- rustfmtで整形したコードを前提にする。テストモジュールの中に行頭から始まる行があると、そこから後ろを本体と数えることがある。
- Rust以外の言語では、本体と同じファイルにあるテストは、本体として数える。

## 必要なもの

- Node.js 24以降
- Git

Node.jsがTypeScriptを直接実行するので、ビルドは要らない。

## 使い方

グラフを作って、そのままブラウザで開くには、次を実行する。

```
npm run dev -- [リポジトリのパス]
```

`--`の後ろに、下の表の引数を書ける。パスを省くと、このリポジトリ自身のグラフになる。

```
npm run dev -- F:/work/my-app --days 30
```

ブラウザを開かずに、HTMLだけを作るには、次を実行する。

```
node src/main.ts [リポジトリのパス] [--days 日数] [--out 出力ファイル] [--open]
```

| 引数             | 意味                         | 既定値             |
| ---------------- | ---------------------------- | ------------------ |
| リポジトリのパス | 調べるGitリポジトリ          | 現在のディレクトリ |
| `--days`         | 最初に出す期間の日数         | `14`               |
| `--out`          | 出力するHTMLファイル         | `churn-chart.html` |
| `--open`         | 出力したHTMLをブラウザで開く | 開かない           |

`--days`には、`7`・`14`・`30`のどれかを書く。ほかの期間も、ページの上のボタンで見られる。

例:

````
node src/main.ts F:/work/my-app --out my-app.html
```棒や点にマウスを載せると、その日の数値が出る。「表で見る」を開くと、同じ数値が表で出る。

## 数え方

- 対象は、現在のブランチのコミットである。
- 日付は、コミット日時（ローカルのタイムゾーン）で決める。
- マージコミットそのものは数えない。マージされた各コミットを数える。
- バイナリファイルは数えない。
````
