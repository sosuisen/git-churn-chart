# features

- Gitのログを読む
  - ファイルごとに、コミットの日付・パス・追加した行・削除した行を返す
  - 新しく作ったファイルと、名前を変えたファイルは、新しいパスで返す
  - 消したファイルは、元のパスで返す
  - 見出しのように見える変更行も、変更行として数える
  - 「ファイル末尾に改行なし」の印と、変更していない前後の行は数えない
  - バイナリファイルは結果に入らない
- コードを見分ける
  - 一覧にある拡張子のファイルはコードである。大文字と小文字は区別しない
  - ドキュメント・設定・ロックファイル・画像はコードではない
  - HTML・CSSと、スクリプト（シェル・PowerShell・バッチ・Python・Kotlin Script）はコードではない
  - 拡張子のないファイルはコードではない
- テストを見分ける
  - パスで見分ける
    - テスト用のディレクトリの中のファイルはテストである
    - 名前がTestsで終わるディレクトリの中のファイルはテストである
    - 名前がテストを表す語で始まるか終わるファイルはテストである
    - testという文字を含むだけの名前は、テストではない
  - Rustは、同じファイルの中のテストを行単位で見分ける
    - テストモジュールの中の変更は、テストとして数える
    - 新しく書いたファイルでは、`#[cfg(test)]`から後ろをテストとして数える
    - テストモジュールを閉じたあとの行は、本体として数える
    - `#[cfg(test)]`の付いた1行の宣言やimplブロックも、テストとして数える
- 日ごとに集計する
  - 期間は終了日を含み、古い日から順に並ぶ
  - 同じ日の変更は合計する
  - 変更のない日は0行である
  - 累計は、期間の最初の日からの純増の合計である
  - 期間の外の変更は無視する
- グラフを分ける
  - グラフは、コード本体・テストコード・すべてのファイルの順に並ぶ
  - コード本体とテストコードの見出しに、対象の拡張子を表示する
  - コードでないファイルは、すべてのファイルにだけ入る
  - テストのパスにあっても、コードでないファイルはテストコードに入らない
  - Rust以外のファイルは、行単位では分けない
- グラフを描く
  - 追加のある日に追加の棒を、削除のある日に削除の棒を描く
  - 累計の線は、日ごとに1つの点を持つ
  - 線の終点に、期間全体の純増を表示する
  - 縦軸の目盛りは切りのよい数である。間隔は1より小さくならない
  - 縦軸が10,000に届くとき、目盛りをKで書く
  - 横軸の日付は、月と日を先頭の0なしで書く
- ページを作る
  - セクションごとに、見出し・グラフ・表を、渡した順に上から並べる
  - 各セクションのグラフは、そのセクションの行数を表示する
  - 期間の最初の日と最後の日を表示する
  - 表に、日ごとの追加・削除・純増・累計が並ぶ
  - リポジトリ名はエスケープして表示する
